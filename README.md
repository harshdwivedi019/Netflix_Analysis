# 🎬 Netflix Data Analysis

A Python-based data analysis project exploring Netflix movies and TV shows to uncover trends in content, genres, countries, ratings, and release patterns.

## 📌 Overview
This project analyzes the Netflix dataset to extract actionable insights using data cleaning, exploratory data analysis (EDA), and visualizations].

## 📊 Dataset
- **File**: `mymoviedb.csv.csv`
- **Source**: Kaggle – Netflix Dataset
- **Contents**: ~9,000–10,000 movies & TV shows with title, type, genre, rating, release year.

## 🛠️ Technologies Used
- Python
- Pandas (data manipulation)
- NumPy (numerical operations)
- Matplotlib & Seaborn (visualization)

## 🚀 How to Run
1. Download `mymoviedb.csv` from Kaggle
2. Open `netflix.py` in Jupyter Notebook or Google Colab
3. Install dependencies:
   ```bash
   pip install pandas numpy matplotlib seaborn plotly
   ```
4. Run all cells to reproduce visualizations and insights.
